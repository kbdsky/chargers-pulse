# ⚡ Project Guidelines: ChargersPulse 2.0 (LA Chargers Intelligence)

## 🏈 Domain Rules
1. **Scope**: Strictly focused on the NFL team **Los Angeles Chargers** (LA Chargers).
2. **Proper Nouns**: Player names (`Justin Herbert`, `Jim Harbaugh`, `Tyler Biadasz`, `Joe Alt`), coach names, and team names (`Chargers`, `49ers`, `Chiefs`, `Raiders`) must remain in **pristine English**.
3. **Language**: All user communications, briefings, takeaways, and article summaries must be written in **100% natural, fluent Korean**.
4. **Data Integrity**: Filter out all HTTP/server error snippets (`Error 500`, `Server Error`, `That's an error`).
5. **Automation & Mobile**: Always support mobile PWA (`newspulse.mobile_launcher`) with zero-config public HTTPS tunnels and GitHub Actions 24/7 cloud cron automation.
